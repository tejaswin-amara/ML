## 📖 Course Overview
**Machine Learning (25SC2107E)** follows an **Outside-in · Project-driven** pedagogy. This repository tracks the evolution from a simple script to a production-grade ML system.

### 🎯 Course Outcomes
| ID | Outcome | Description |
| :--- | :--- | :--- |
| **CO1** | **Lifecycle** | Analyze end-to-end ML system lifecycles. |
| **CO2** | **Supervised** | Apply linear models and regularization techniques. |
| **CO3** | **Tree-based** | Master Random Forests, XGBoost, and LightGBM. |
| **CO4** | **Unsupervised** | Implement Clustering, PCA, and UMAP. |
| **CO5** | **Evaluation** | Rigorous model performance analysis using CV. |
| **CO6** | **Engineering** | ML-engineering practices for production deployment. |
