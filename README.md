# MLNG · Machine Learning (PBL Track)

## Course Overview
This repository tracks the progress of the **MLNG - Machine Learning** course (25SC2107E). The track follows an **Outside-in, Project-driven (PBL)** pedagogy, focusing on classical ML canon, model-evaluation discipline, and ML-engineering pipelines.

### Repository Structure
- **week 1/**: Python Primers, Logic Scripts, and initial datasets (Placement Predict 50k).
- **week 2/**: Titanic Analysis - Data loading and initial exploration.

### Course Objectives
- Analyze end-to-end ML system lifecycles.
- Apply linear supervised-learning models (Regression, Logistic).
- Apply tree-based models (Random Forests, XGBoost, LightGBM).
- Apply unsupervised-learning techniques (K-means, DBSCAN, PCA).
- Analyze model performance using CV and advanced metrics.
- Apply ML-engineering practices (FastAPI serving, Monitoring).

### Tool Stack
- **Languages**: Python 3.11+
- **Libraries**: pandas, NumPy, scikit-learn, XGBoost, Optuna, FastAPI
- **DevOps**: Docker, MLflow, Git
