## 📖 Overview
This repository represents a structured journey through the **Machine Learning (25SC2107E)** course. It follows a professional nested architecture to separate practical implementation from skill development.

---

## 🏗️ Repository Architecture

### 📅 [Week 1: Foundations](./week%201/)
*   **Practical**: Python Primers and Data Ingestion logic.
*   **Skill**: Tool configuration and environment setup.
*   **Key Reports**: Outlier Analysis and Statistical Summaries.

### 📅 [Week 2: Data Engineering](./week%202/)
*   **Practical**: Titanic Dataset processing and feature engineering.
*   **Skill**: Advanced manipulation techniques.
*   **Key Reports**: Detailed EDA and Data Cleaning pipelines.

### 📅 [Week 3: Advanced EDA](./week%203/)
*   **Practical**: Comparative analysis of Iris, Diabetes, and MTCars datasets.
*   **Skill**: Visualization and correlation matrix mastery.
*   **Key Reports**: Master EDA Summary for all datasets.
